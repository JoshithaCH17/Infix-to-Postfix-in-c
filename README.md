# Infix to Postfix Conversion in C

A C program that converts infix expressions
into postfix expressions using a stack.

## Features
- Stack-based expression conversion
- Operator precedence
- Parentheses handling
- Right-associative exponentiation

## Example

Input:
A+B*C

Output:
ABC*+

## Concepts Used
- Stack
- Arrays
- Operator Precedence
- Expression Conversion

## Limitations
- Single-character operands
- No spaces in expressions
- Assumes well-formed input

## How to Run

Compile:
gcc infix_to_postfix.c -o infix_to_postfix

Run on Windows:
.\infix_to_postfix.exe

## Language
C
